1. Watch the [demo video](https://www.youtube.com/watch?v=pivk3KyXpEQ) to see agreement review, billing controls, and a separate PayPal Sandbox draft example.
2. Use [Explore the workflow](USER_GUIDE.md) to understand what each screen does.

4. Consult [Validation and limitations](VALIDATION.md) to distinguish reproducible checks from historical or externally unverified evidence.
