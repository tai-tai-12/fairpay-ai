# Architecture
Browser public/ → loopback Node server.mjs → deterministic source policy, contract-invariants, receivables, project-model → project-store atomic local JSON. Agreement versions and ledger revisions bind human acceptance and exact net authorization. paypal-adapter performs Sandbox readback and unknown-write lockout. AI extracts untrusted candidate terms; it has no financial authority. Evaluation/scorer uses synthetic workflow simulation, not external verification. No npm runtime dependencies; Node >=22 required. PDF/DOCX import may depend on platform utilities; paste text is the portable starting path.
