# Security and privacy
NON-RELEASE, single-user loopback only; Host/Origin checks are not multi-tenant authentication. Do not expose publicly. Never supply real credentials, private agreements or financial records in this review. PayPal writes of every kind are prohibited in this engineering task; all automated financial tests use loopback mocks.
Gross fee ≠ outstanding receivable ≠ authorized amount. Human-recorded credit is not bank-verified receipt; recorded acceptance does not authenticate a buyer. DRAFT is unsent, UNKNOWN remains blocked, stored PAID is not bank settlement proof. Retain current ledger/version/exact amount/currency/caps/idempotency checks.
Local .local-data is not encrypted; store synthetic data only. Delete only your explicitly selected synthetic local data after stopping this copy if desired; never merge historical stores. Source ZIP excludes private state and Git. Scanner checks obvious patterns and forbidden paths, not forensic PII certification. Optional cloud AI sends source text externally; default Ollama is local. No telemetry claim beyond inspected application behavior; browser/provider services have their own policies.
